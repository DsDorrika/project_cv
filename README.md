# Система детекции пересечения линии

Система компьютерного зрения для автоматического обнаружения пересечения виртуальной линии объектами (людьми) с сохранением нарушений и звуковым оповещением.

## 🚀 Особенности

- **🎥 Захват видео** в реальном времени с веб-камеры или файла
- **🤖 Детекция объектов** с использованием MobileNet-SSD или демо-режима
- **📏 Контрольная линия** с настраиваемыми координатами
- **🔊 Звуковое оповещение** при обнаружении нарушений
- **💾 Сохранение доказательств** - фото и метаданные нарушений
- **📊 Графический интерфейс** с отображением статистики
- **⚡ Высокая производительность** с оптимизацией для CPU

## 📋 Требования

### Аппаратные
- Веб-камера или видеофайл
- 2+ ГБ оперативной памяти
- Процессор с поддержкой AVX (для нейронных сетей)

### Программные
- Python 3.8+
- Windows/Linux/macOS

## 🎯 Использование

### Быстрый старт
```bash
python main.py
```

### Основные возможности

1. **Запуск системы** - автоматически начинает детекцию
2. **Тест звука** - проверка звукового оповещения
3. **Пауза/возобновление** - клавиша 'p'
4. **Сброс статистики** - клавиша 'r'
5. **Сохранение кадра** - клавиша 's'
6. **Выход** - клавиша 'q' или ESC

### Горячие клавиши
- **Q / ESC** - выход из приложения
- **P** - пауза/возобновление детекции
- **R** - сброс статистики
- **S** - сохранение текущего кадра

## ⚙️ Конфигурация

Основные настройки в файле `config.py`:

### Видеопоток
```python
VIDEO_SOURCE = 0  # 0 - веб-камера, путь к файлу - видеофайл
CAMERA_RESOLUTION = (1280, 720)
```

### Контрольная линия
```python
CROSSING_LINE_COORDS = (320, 360, 960, 360)  # x1, y1, x2, y2
```

### Детектор объектов
```python
# MobileNet-SSD (рекомендуется для CPU)
DETECTOR_MODEL_PATH = "models/MobileNetSSD_deploy.caffemodel"
DETECTOR_CONFIG_PATH = "models/MobileNetSSD_deploy.prototxt"
```

### Демо-режим
Если модели не найдены, система автоматически переходит в демо-режим с искусственными объектами.

## 🔧 Настройка моделей

1. Скачайте файлы модели:

## 🐛 Решение проблем

### Проблема: "Не удалось открыть источник видео"
**Решение:** Проверьте подключение камеры или путь к видеофайлу в `config.py`

### Проблема: "Модели не найдены"
**Решение:** 
- Скачайте модели MobileNet-SSD (см. раздел "Настройка моделей")
- Или используйте демо-режим (автоматически активируется)

### Проблема: "Низкий FPS"
**Решение:**
- Уменьшите разрешение в `config.py`
- Увеличьте `PROCESS_EVERY_N_FRAME`
- Используйте `RESIZE_FRAME_FOR_PROCESSING`

### Проблема: "Нет звука"
**Решение:**
- Убедитесь, что файл `sounds/beep.wav` существует
- Проверьте настройки громкости системы
- Включите звук в `config.py`: `SOUND_ENABLED = True`
