# Система детекции пересечения линии

Система компьютерного зрения для автоматического обнаружения пересечения виртуальной линии объектами (людьми) с сохранением нарушений и звуковым оповещением.

## 🚀 Особенности

- **🎥 Захват видео** в реальном времени с веб-камеры или файла
- **🤖 Детекция объектов** с использованием YOLOv8 (рекомендуется)
- **📏 Контрольная линия** с настраиваемыми координатами
- **🔊 Звуковое оповещение** при обнаружении нарушений
- **💾 Сохранение доказательств** - фото и метаданные нарушений
- **📊 Графический интерфейс** с отображением статистики

## 📋 Требования

- Python 3.8+

Зависимости перечислены в `requirements.txt` (opencv-python, ultralytics, numpy, pygame, requests).

## 🛠 Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение
3. Установите зависимости:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. Убедитесь, что в папке `models/` есть `yolov8n.pt`. Если файла нет, приложение попытается скачать его автоматически.

## 🎯 Использование

Запустите приложение:

```powershell
python main.py
```

Горячие клавиши:
- Q / ESC — выход
- P — пауза/возобновление
- R — сброс статистики
- S — сохранение текущего кадра

## 🧠 Правило фиксации нарушений

Проект теперь использует YOLOv8 для детекции. Правило фиксации нарушения:
- Стандартное: когда объект (person) пересекает контрольную линию — фиксируется нарушение.
- Дополнительное простое правило: если человек находится в пределах 30 пикселей от линии и остается там более 1 секунды — это также фиксируется как нарушение (помогает ловить стоящие на линии случаи).
- Чтобы избежать спама, для одного объекта действует минимальный интервал между фиксациями (см. `MIN_VIOLATION_INTERVAL_SECONDS` в `config.py`, по умолчанию 60 сек).
